# 自選股與可編輯行情方塊

首頁、市場、公司頁各有獨立方塊配置。按「＋新增方塊」選股票、大小、圖表與期間；卡片右上「•••」可逐一編輯。「編輯方塊」模式可移除、用左右按鈕調整順序，桌面也可拖曳。

## 自選關注

星號代表自選關注。按上方「自選股」管理共用關注清單，並可從清單把股票加入目前頁面。關注與顯示分開：取消關注不會偷偷移除既有頁面方塊。

每頁最多12個方塊、最多關注60檔。相同股票可以建不同期間或圖表的方塊。支援來源可查詢的台股、美股、ETF及指數；台股可輸入 `2330`，上櫃可輸入 `6488.TWO`，美股如 `NVDA`、`AAPL`。常用名稱可從輸入清單選擇；清單以外請輸入代碼，並先確認股票。

設定保存於這部裝置的瀏覽器／主畫面Web App，不需登入，也不會修改其他讀者的頁面。Safari與主畫面App、不同瀏覽器及手機／電腦的資料不保證共用。清除網站資料會移除設定；可在「自選股 → 備份與還原」下載JSON，於另一環境匯入。

## 真實折線與 K 棒

- 1日：來源提供的5分鐘OHLCV；休市時顯示最近可取得的交易時段。
- 1月、3月、1年：日OHLCV。
- K棒使用開盤、最高、最低、收盤資料，缺欄不補造；缺乏完整資料時顯示缺漏。
- 折線連接來源實際收盤／每根分時棒收盤值，沒有隨機曲線或以最後價格推造中間走勢。
- 紅漲綠跌；紅K代表收高於開，綠K代表收低於開，十字／同價K為中性色。卡片漲跌是相對上一交易日收盤，與K棒顏色的比較基準不同。
- 顯示價格刻度、實際日期、成交量及區間變動幅度。移動游標、觸碰或使用左右方向鍵可查看單根的日期、開高低收與成交量。
- 點股票名稱或「詳細行情」開啟大閱讀窗，可切換圖表及期間，並查看站內已有的相關新聞。詳細窗中的期間切換是閱讀設定；要永久改變方塊，請用「•••」編輯。

## 資料與限制

行情來自Yahoo Finance公開資料，可能延遲，不能當作交易所或券商逐筆即時報價。卡片標示來源時間；美股使用來源的交易所時區。資料可能依公司行動調整，應對照來源原始頁面。

公開晨報每日保留九種預設指數／標的的日行情快照；自選股會在開啟頁面時經雲端服務查詢。服務端快取約2分鐘，瀏覽器快取約1分鐘。來源失敗時，僅在有既有快照的情況下顯示標明時間的備援；不拿日線冒充5分鐘線，不補入假價格。

行情服務只快取公開股票資料，不保存個人自選清單。它與推播服務共用部署，但訂閱資料及私鑰仍保密。更改個人自選不會自動改變所有人共用的十則晨報內容。

## 修改與驗證

- `ui/widget-model.js`：方塊與自選設定、資料清理、預設股票。
- `ui/widgets.js`：新增／編輯／排序、行情讀取、完整行情窗、備份。
- `ui/stock-chart.js`：實際OHLCV圖表與游標。
- `ui/widgets.css`：方塊大小、動畫、手機版。
- `push-service/market.mjs`：行情解析及雲端查詢的審閱副本；後端需另透過Sites部署。
- `verify-widgets.mjs`、`push-service/verify-market.mjs`：設定與行情正確性檢查。
- `verify-live-market.mjs`：實際雲端台股／美股／上櫃／分時資料檢查。
